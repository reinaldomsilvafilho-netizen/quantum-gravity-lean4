# Corrections of 2026-09-25: *Simplicial Quantum Gravity on Δ4 × Δ2*

File: `manuscript_simplicial_quantum_gravity_master.tex`. This note also serves as the Zenodo version note.

This pass aligns the manuscript with the audited monograph *Geometry, Tensors, and Quantum Gravity* v2.3 (concept DOI 10.5281/zenodo.22290043): Ch. 2, 3, 4, 8, 11, 12, 13, `CHANGELOG.md`, and the referee files `audit/verify/ch12_blind.md` and `fixes_F41-F43.md`. The rule was simple. Where the book proves something, the manuscript agrees with it. Where the book states a conjecture, the manuscript does not call it a theorem.

The evidence script is `check_sqg_formulas.py` in this folder. Every check in it has an independent oracle and a negative control, and it exits with code 0. `check_refs_sqg.py` resolves the bibliography DOIs through Crossref and DataCite. A copy of the manuscript before this pass is kept outside the repository (scratchpad) and can be recovered from git.

The title changed from "...Non-Perturbative UV Regularization, L∞-Minimax Foliations, and Standard Model Gauge Condensation" to "...A Two-Scale Spectral Dimension, L∞-Minimax Foliations, and Conjectures on Gauge and Flavor Structure".
